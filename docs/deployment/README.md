# Deployment and Self-Hosting

Docker Compose is the reference deployment.

The deployment experience should be deliberately simple for a FOSS operator.

Document requirements, installation, environment configuration, secrets, application, web server, database, Redis, queue worker, scheduler, Meilisearch, persistent storage, health checks, mail, backups, upgrades, rollback/recovery, logs, and troubleshooting.

Prefer a release-based deployment over requiring operators to build the application from source.
