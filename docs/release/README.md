# Releases

Nusszopf is released as a self-hostable FOSS application.

The release process should be predictable and reproducible.

Document versioning, changelog, release notes, Git tags, GitHub Releases, CI validation, Docker image publishing, release artifacts, upgrade instructions, migration handling, rollback, breaking changes, and security releases.

Use Waffle Dashboard as a process reference and LCxHolz/Laravel Docker examples for implementation patterns.
